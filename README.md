# Recipe

## Description
This project is a recipe website/app where users can view, add, and manage different recipes. It is built using HTML, CSS, and JavaScript.

## Features
- View recipes
- Add new recipes
- Delete recipes
- Search recipes

## Technologies Used
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository
   git clone https://github.com/irene18boyles/Recipe.git

2. Install dependencies
   npm install

3. Run the project
   npm start
